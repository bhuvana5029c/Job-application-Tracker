# Job Application Tracker (CLI)

A Python command-line application to manage and organize job applications efficiently.

## Features

- Add new job applications
- View all applications sorted by applied date
- Search by company or job role
- Filter applications by status
- Update application status
- Delete applications
- View application statistics
- Upcoming interview reminders
- Success rate and application funnel report

## Technologies Used

- Python
- JSON
- File Handling
- Functions & Modules
- CLI (Command Line Interface)

## Project Structure

```
main.py            # Entry point
application.py     # Core application logic
storage.py         # Read/write JSON data
search.py          # Search functionality
report.py          # Statistics & reports
utils.py           # Utility functions
applications.json  # Stores application data
```

## How to Run

```bash
python main.py
```
